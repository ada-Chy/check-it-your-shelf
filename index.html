How to use

1. Tap ➕ Add to record a product + batch.

2. Use the + / − buttons on each batch to adjust quantity quickly.

3. Tap Using or Finish to change status.

4. Check 🛒 List for items that need restocking.

5. Regularly create a backup in Settings (recommended every 1–2 weeks).
